## 🚀 Principais Projetos

### [SureBets Analyzer](https://github.com/HenriqueNeimog/surebets-analyzer)  
Ferramenta em **Node.js** que coleta odds da Pinnacle e Betfair Exchange, identifica oportunidades de **surebets** e dispara alertas em tempo real.  
- Integração com APIs REST  
- Processamento em Workers a cada 30s  
- Armazenamento de dados e gerenciamento de filas com Redis  

### [Sistema de Controle de Pedidos](https://github.com/HenriqueNeimog/pedido-system)  
Aplicação full-stack para cadastro de usuários, fornecedores, produtos e relatórios detalhados de compras.  
- Backend em NestJS + Prisma  
- Frontend SPA (React)  
- Exportação de relatórios em PDF  

### [Restaurant Order System](https://github.com/HenriqueNeimog/restaurant-weight-system)  
Sistema de pedidos por peso integrado a balança, com numeração de mesas e associação por garçom.  
- Comunicação serial com balança  
- Dashboard em tempo real para cozinha  
- Histórico de vendas  

### [Rifa Processor](https://github.com/HenriqueNeimog/rifa-processor)  
Serviço de processamento de rifas usando cron jobs, Redis e worker threads para atualizar status, expirar pagamentos e gerenciar cotas.
